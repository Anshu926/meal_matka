# 🍽️ Online Food Ordering System for Cafeteria

A full-stack web application that simplifies food ordering in a cafeteria by allowing users to browse menus, place orders, and manage their cart through a responsive and user-friendly interface.

The project is designed to provide a seamless online food ordering experience while demonstrating full-stack web development concepts using Node.js, Express.js, MongoDB, and EJS.

---

## ✨ Features

- 🍔 Browse categorized food items
- 🛒 Add and remove items from the cart
- 📝 Place food orders online
- 👤 User-friendly interface
- 📱 Responsive design for desktop and mobile
- ⚡ Fast and dynamic page rendering
- 💾 MongoDB database integration

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Anshu926/meal_matka.git
```

### Navigate to the project

```bash
cd meal_matka
```

### Install dependencies

```bash
npm install
```

### Configure MongoDB

Update your MongoDB connection string in the configuration file.

### Run the project

```bash
npm start
```

or

```bash
node app.js
```
